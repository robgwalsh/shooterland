# Shooterland: gap register

Rules and constants that could not be recovered with confidence from the surviving data
alone. Every tunable constant in the engine lives in `packages/shooterland/src/core/rules.ts`;
those that were guesses carried a `// GAP:Gn` comment and have now been replaced by the
verified values.

Status values: `open`, `verified-exe` (observed in the legacy exe), `verified-disasm` (read
from the disassembly; see [DISASSEMBLY.md](DISASSEMBLY.md) for the function map),
`decided` (we chose a rule).

The Ghidra pass (2026-10-19) read every function of the 77 KB exe, which settled all 26
original gaps and found two more (G27, G28). The exe sessions in
[RECONCILIATION.md](RECONCILIATION.md) are now only needed for the things a disassembly cannot
show: how the animations and timings feel, and the audio mix.
